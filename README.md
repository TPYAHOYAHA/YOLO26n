# 硬貨スキャナー

iPhone向けのオフライン日本円硬貨検出。背面の通常広角カメラを縦向き・30fpsで使用します。写真・動画の保存機能はありません。

## WindowsからIPAを作る

1. このZIPを展開し、隠しフォルダの `.github` を含む全ファイルを、GitHubの自分用リポジトリの `main` に追加します。
2. Actionsの「Build iPhone IPA」が成功したら、実行結果の Artifacts から `coin-detector` をダウンロードします。手動実行には Run workflow を使えます。
3. ダウンロードしたZIPを展開し、`coin-detector.ipa` をiPhoneのファイルアプリに移します。SideStoreでIPAを選び、署名してインストールします。

Windowsに追加ツールは不要です。GitHubのmacOSランナーにあるCocoaPodsが固定バージョンのONNX Runtimeを取得し、Xcodeでビルドします。Apple IDや署名情報をGitHubへ登録する必要はありません。最低対応はiOS 17です。

## モデル

硬貨6クラスのYOLO26n、Float32、バッチ1、end-to-end ONNXを選んでください。クラスIDは **1円、5円、10円、50円、100円、500円** の順です。出力は `[1, 件数, 6]` です。外部ウェイトを参照するONNXには対応しません。

固定解像度のファイルでは、そのモデルに合う解像度だけを表示します。320・416・640の別々のファイルを使うなら、別名で保存して設定から差し替えてください。動的モデルでは、推論の確認に成功したサイズを選べます。

## 動作確認

- 416モデルで起動して検出枠が向き・位置ともに合うか確認してください。5円や500円を含む、金額が既知の組み合わせで検証します。
- 推論上限は標準10fps。CPUの%はアプリの使用量で、1コアを100%とするため100%を超えることがあります。メモリはアプリの物理メモリ使用量です。
- Core ML EPの表示はプロバイダーの設定を示します。グラフの一部がCPUで実行される場合があります。GPU・Neural Engineへの実際の割り当てはこの画面では計測しません。
- 設定のリセットは416・10fps・信頼度0.25・追跡IoU 0.45・安定化オンに戻します。インポート済みのモデルは保持します。
